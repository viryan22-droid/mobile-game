# 🎮 Mobile Jump Game

Un jeu vidéo simple et amusant jouable directement dans votre navigateur sur **téléphone, tablette ou ordinateur** !

## 🚀 Comment jouer ?

1. **Appuyez sur l'écran** (téléphone/tablette) ou **la barre d'espace** (ordinateur) pour sauter
2. **Évitez les obstacles** qui arrivent de droite à gauche
3. **Gagnez des points** en esquivant les obstacles
4. Le jeu devient **plus difficile** au fur et à mesure

## 📱 Tester le jeu sur GitHub Pages

### Étape 1 : Activer GitHub Pages
1. Allez sur votre repository : https://github.com/viryan22-droid/mobile-game
2. Cliquez sur **Settings** (Paramètres)
3. Dans la barre latérale gauche, cliquez sur **Pages**
4. Sous "Build and deployment" → "Source", sélectionnez **Deploy from a branch**
5. Sélectionnez la branche **main** et le dossier **/ (root)**
6. Cliquez sur **Save**

### Étape 2 : Accéder au jeu
Après quelques secondes, vous verrez une notification verte avec votre URL :
```
Your site is published at: https://viryan22-droid.github.io/mobile-game/
```

Cliquez sur ce lien pour jouer ! 🎮

### Étape 3 : Partager le lien
Vous pouvez maintenant partager ce lien avec vos amis pour qu'ils testent votre jeu !

## 🎮 Contrôles

| Plateforme | Action |
|-----------|--------|
| **Téléphone/Tablette** | Touchez n'importe où sur l'écran |
| **Ordinateur (Clavier)** | Appuyez sur la **barre d'espace** |
| **Ordinateur (Souris)** | Bougez la souris à gauche/droite pour vous déplacer |

## 📊 Points

- Chaque obstacle esquivé = **+10 points**
- Le jeu s'accélère tous les **100 points** 

## 🛠️ Personnalisation

Vous pouvez modifier :
- Les couleurs dans `style.css`
- La vitesse du jeu dans `game.js`
- Les obstacles et leur taille

## 📄 Fichiers

- `index.html` - Structure du jeu
- `style.css` - Design et responsivité mobile
- `game.js` - Logique du jeu
